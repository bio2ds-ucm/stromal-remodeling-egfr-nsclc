# Intermediate results

Intermediate files produced by the analysis scripts are **not versioned**.
They are regenerated by running the scripts in `Scripts/2_Data_analyses/`
in order.

The subfolder structure mirrors the analysis scripts:

```
Results/Intermediate/
├── Cell_line_models/
│   ├── Osimertinib_resistance/
│   └── Persistence/
├── H12O_TMA004_cohort/
└── OSIRESP_and_OSIREAL_cohorts/
```
